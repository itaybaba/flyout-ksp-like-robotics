# Changelog

## v1.0.0 - 2026-10-14

First public release as **KSP-Like Robotics v1**.

- Hydraulic Cylinder and Telescopic Hydraulic Cylinder with real joint physics. Attached parts move, and cylinders can be stacked.
- Uniform-only scaling: bigger cylinders are longer, wider and stronger.
- Min/Max extension, speed, force limit, invert, and hangar preview that carries attached parts. Min extension is shown in the hangar and is where flight starts. Min and max can't cross.
- Visual-only Hide model button.
- KAL-1000 controller with a KSP-style track editor: Once/Repeat/Ping-Pong, Smooth/Linear/Flat points, copy/paste, flip, symmetry, play on launch and key bindings. It can drive any input, including native hinges.
- Part files ship inside the DLL and are installed to Flyout's mod parts folder on startup.
- Optional Windows installer with Steam library detection, folder validation, DLL backup and a manual folder picker.
